🎯 Методика: как вести

🕑 90-минутные блоки

Нейробиология: мозг фокусируется циклами ~90 мин (ультрадианный ритм, Huberman). После — обязательный перерыв с движением. Не пытайся растянуть блок.

🤝 Pair Programming

Driver (пишет) + Navigator (направляет). Менять роли каждые 15-20 мин. Сильный + начинающий в одной паре. Менять пары между блоками.

🎲 Геймификация

Командный leaderboard (НЕ индивидуальный). Баллы за: помощь другим, креативность, скорость, лучший вопрос. Финальное голосование.

📚 Scaffold (3 уровня)

Новичок: готовый код, заполни пропуски
Средний: скелет + подсказки
Продвинутый: только бриф и API-доки
Все приходят к одному результату!

🇪🇹 Каш: контекст для заданий

Каш (Антифеллос) — не просто город. Это 3000+ лет истории на одном полуострове.

🏛 Античфеллос

Город основан ликийцами (XV в. до н.э.). Чеканил собственные монеты. Эллинистический театр на 4000 мест. Львиная гробница (2400 лет). 100+ скальных гробниц.

🚢 Корабль Улубурун

1982: ныряльщик за губками нашёл медные слитки. XIV век до н.э. 20 тонн груза из 10 культур. 22,413 погружений. Одно из главных открытий подводной археологии.

🌊 Затонувший Кекова

Ликийский город ушёл под воду после землетрясений. В 1990 запретили плавание (мародёры). Номинирован в UNESCO. 40 км от Каша.

🇬🇷 Остров Меис

Греческий Кастеллоризо — 2.1 км от Каша. 20 мин на пароме. Две страны, две валюты, два мира. Оскар за "Средиземноморье" (1991).

Виллы от €200K. Люкс €500K-2M. Рост ~12%/год. Дешевле Бодрума.

👥 Население

⚖ Legal & Этика

Озвучить в начале дня. 2 минуты. Серьёзно, но без паники.

🚫 Нельзя

  • Подключаться к чужим устройствам / сетям без разрешения
  • Собирать персональные данные (KVKK = турецкий GDPR)
  • Сканировать чужие WiFi-сети (только свою!)
  • Создавать токены для реального fundraising
  • Stalking / сбор данных о конкретных людях

✅ Можно

  • Shodan / Censys — легальный индекс публичных банеров
  • OpenStreetMap, Overpass API — открытые данные
  • Публичные вебкамеры (windy.com, skylinewebcams)
  • AIS / ADS-B — корабли и самолёты вещают открыто
  • Токены на devnet/testnet — образовательные цели
  • Пассивный WiFi-скан (airport -s) — только наблюдение

Турецкое законодательство: Закон 5651 + УК ст. 243-244: несанкционированный доступ к компьютерным системам — от 1 до 3 лет. Закон 6698 (KVKK): обработка персональных данных без согласия запрещена. Мы работаем только с публичными данными и своей сетью.
