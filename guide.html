Пошагово

Шаг 1
Установить Claude Code
npm install -g @anthropic-ai/claude-code

Если нет npm — сначала brew install node (macOS) или скачать с nodejs.org

Шаг 2
Запустить и авторизоваться

Тим раздаст API-ключи. Или используйте свой аккаунт Anthropic.

Шаг 3
Включить Bypass Permissions
# В Claude Code набрать: /permissions # Добавить разрешения для Bash, Read, Write, Edit — Allow All

Это позволит Claude действовать автономно, без подтверждений на каждое действие.

Шаг 4

Подключить Playwright MCP

Шаг 6
Подключить GitHub
gh auth login # Следуйте инструкциям. Потом проверьте: gh auth status

Делите задачи между собой как хотите. Один пишет смарт-контракт, другой делает метаданные, третий разбирается с раздачей. Консенсус — ваша ответственность.

Что нужно сделать

1. Создать Jetton (токен) в TON

TON — блокчейн Telegram. Jetton — стандарт токена в TON (аналог ERC-20). Используйте Claude Code для написания и деплоя смарт-контракта.

# Попросите Claude Code: "Создай Jetton токен в блокчейне TON. Название: BOTANICA Символ: BOT Общее количество: 1,000,000 Задеплой в testnet. Используй Blueprint framework."

2. Раздать всем в комнате

Каждый участник должен получить токены в свой Telegram Wallet. Придумайте механизм раздачи: airdrop, ссылка, бот, ручная отправка — как хотите.

# Варианты: # 1. Через Telegram Wallet API # 2. Написать бот для раздачи # 3. Ручной трансфер каждому # 4. QR-код для получения

3. Договориться об экономике

Этот токен будет использоваться весь день. Решите:

  • Сколько токенов получает каждый на старте?
  • За что можно заработать ещё?
  • Что можно купить за токены?
  • Будет ли "обменный курс"?

4. Подготовить инфраструктуру

Для Урока 2 каждый будет строить бизнес на этом токене. Подготовьте:

  • Документацию: как интегрировать ваш токен
  • API / SDK / примеры кода для приёма токенов
  • Простой способ проверки баланса

💡 Подсказка от Тима: TON Blueprint — официальный framework для смарт-контрактов TON. npm create ton@latest создаст проект. Jetton стандарт задокументирован на docs.ton.org. Claude Code знает TON.

💡 Как конструировать мега-промпт

Структура промпта:
  1. Роль и контекст
  2. Конечный результат (что должно получиться)
  3. Технический стек
  4. Бизнес-логика + интеграция BOT-токена
  5. Дизайн и UX требования
  6. Деплой и финализация
Пример начала:
"Ты — full-stack разработчик. Создай полностью рабочий сервис аренды яхт в Каше. Результат: 1. Landing page (HTML/CSS/JS) 2. Каталог яхт (JSON + UI) 3. Система бронирования 4. Оплата в BOT-токене (TON) 5. Telegram-бот для клиентов 6. GitHub repo + README 7. Деплой на GitHub Pages Стиль: средиземноморский, тёплые цвета, фото Каша."

⚡ Совет Тима: Не бойтесь длинных промптов. Claude Code справляется с промптами на 1000+ слов. Чем точнее описание — тем ближе результат к идеалу. Используйте MCP-серверы внутри промпта: "используй Playwright чтобы...", "отправь в Telegram..."
