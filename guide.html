mkdir ~/botanica && cd ~/botanica && claude

Войдите через свой аккаунт Anthropic (Claude Pro / Max). Свои ключи, своя подписка.Log in with your Anthropic account (Claude Pro / Max). Your keys, your subscription.

3 Снятие ограничений (Permissions)Bypass Permissions

По умолчанию Claude Code спрашивает разрешение на каждое действие. Для воркшопа мы снимаем эти ограничения. Выйдите из Claude (/exit), затем:By default Claude Code asks permission for every action. For the workshop we bypass this. Exit Claude (/exit), then:

claude --dangerously-skip-permissions

⚠ Этот флаг даёт Claude полный контроль: создание файлов, запуск команд, работа с сетью. Используйте только в безопасном окружении (воркшоп, песочница). This flag gives Claude full control: file creation, command execution, network access. Use only in safe environments (workshop, sandbox).

Или настройте разрешения интерактивно (внутри Claude Code): Or configure permissions interactively (inside Claude Code): 

/permissions

4 Голосовой вводVoice input

Установите Handy — голосовой помощник для Claude Code. Говорите промпты вместо того, чтобы печатать:Install Handy — voice assistant for Claude Code. Speak prompts instead of typing:

brew install handy

Создание токена BOT Creating BOT token

Задача: создать Jetton (токен) на TON, который станет валютой буткемпа. Все участники получат BOT-токены. Goal: create a Jetton (token) on TON that becomes the bootcamp currency. All participants will receive BOT tokens.

1 Инициализация проектаInit project

npm create ton@latest

Выберите шаблон Tact. Назовите проект botanica-token.Choose Tact template. Name the project botanica-token.

2 Сборка и тестыBuild & test

cd botanica-token && npm install && npx blueprint build --all && npm test

3 Деплой в тестнетDeploy to testnet

npx blueprint run --testnet --tonconnect

Отсканируйте QR-код через Tonkeeper для подтверждения.Scan QR code with Tonkeeper to confirm.

4 Раздача токеновDistribute tokens

Отправьте BOT-токены каждому участнику через @wallet в Telegram или напрямую на адрес кошелька.Send BOT tokens to each participant via @wallet in Telegram or directly to their wallet address.

Совет: используйте Claude Code для написания смарт-контракта! Скажите ему: "Создай Jetton с названием BOT, символом BOT, supply 1,000,000, и деплой в тестнет TON".Tip: use Claude Code to write the smart contract! Tell it: "Create a Jetton named BOT, symbol BOT, supply 1,000,000, and deploy to TON testnet".

SETUP

Челлендж: один промпт — один бизнес Challenge: one prompt — one business

Ваша задача — написать один мега-промпт, который заставит Claude Code создать полноценный бизнес-проект. Три обязательных условия: Your task — write one mega-prompt that makes Claude Code create a full business project. Three mandatory conditions:

  1. Один промптOne prompt
    Весь бизнес создаётся одной командой. Никаких уточнений, дополнений, переделок. Один промпт — один результат. The entire business is created with a single command. No clarifications, additions, redo. One prompt — one result.
  2. Привязка к КашуConnected to Kas
    Бизнес должен быть привязан к Кашу: местная аудитория, туристы, море, природа, яхты, дайвинг — что угодно из контекста этого города. Business must be connected to Kas: local audience, tourists, sea, nature, yachts, diving — anything from this town's context.
  3. Использует токен BOTUses BOT token
    Бизнес-модель должна интегрировать токен BOT, созданный на уроке 1: оплата, лояльность, доступ, голосование — любой use case. Business model must integrate the BOT token created in lesson 1: payments, loyalty, access, voting — any use case.

Подсказка:Hint: Хороший мега-промпт включает: роль Claude, описание бизнеса, технический стек, структуру файлов, дизайн, деплой. Чем подробнее — тем лучше результат. A good mega-prompt includes: Claude's role, business description, tech stack, file structure, design, deploy. The more detail — the better the result.

Пример промпта:Example prompt: "Ты — fullstack-разработчик. Создай веб-приложение для бронирования дайвинг-туров в Каше. Стек: HTML+CSS+JS (один файл). Принимай оплату в токенах BOT (TON Jetton, адрес: ...). Добавь карту достопримечательностей, форму бронирования, и задеплой на GitHub Pages." "You are a fullstack developer. Create a web app for booking diving tours in Kas. Stack: HTML+CSS+JS (single file). Accept payments in BOT tokens (TON Jetton, address: ...). Add a map of attractions, booking form, and deploy to GitHub Pages."
